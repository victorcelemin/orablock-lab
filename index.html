    ¿Cómo usar IA de forma segura con Oracle?

    Nunca le des acceso directo sin control a una IA sobre tu base de datos. Elige dónde vas a trabajar y la app evaluará tu script Scratch actual para recomendarte el Agente y el Harness ideales.

    ¿Qué es el Agente?

    Es el programa con IA (como Gemini CLI, Claude Code o Codex CLI) que lee tu objetivo, redacta el comando Oracle y detecta errores.

    ¿Qué es el Harness?

    Es el "cinturón de seguridad" que rodea al agente: define qué permisos tiene en Oracle (MCP), si trabaja en una copia desechable (sandbox) y cuándo debe pedirte permiso antes de ejecutar.
